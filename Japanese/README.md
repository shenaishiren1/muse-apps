# Kana Flashcards

Japanese kana flashcards, built with Muse (Omi). Four decks: hiragana and katakana (46 basic kana each, plus an optional voiced/semi-voiced set), Travel words, and Colors.

- Travel and Colors card fronts show the word with its hiragana reading, pitch-marked in the Tokyo style: a red line over the high-pitch morae, a drop tick where the pitch falls, and the accent number
- Kana card backs show the kana beside its romaji, the kana's man'yōgana root character(s), and three example words with their kanji forms and pitch accents
- Three-level self-rating on every card (✗ don't remember · ○ not sure · ✓ got it), with an end-of-deck review round for the missed cards
- Shuffle is off by default — decks open in standard order

## Files

- `Japanese.html` — the complete app as one self-contained HTML file. Open it in any browser; no server or build step needed.
