# Fruit of the Spirit

The nine Fruit of the Spirit (Galatians 5:22–23) as a 3×3 grid of coloured tiles — Love, Joy, Peace, Patience, Kindness, Goodness, Faithfulness, Gentleness, Self-control — built with Muse (Omi).

- Six tiles show large iOS emoji and three show photorealistic artwork; a second, linked image set shows a hand gesture for each fruit instead
- Four independent language toggles — EN, 中 (Traditional Chinese), 日, DE — stack labels on the tiles in that order, with the wording taken from each language's most common Bible translation, and text auto-sized to fill each tile
- The two image buttons work as a pair: press one to show its image set, press it again to hide images, press the other to switch sets directly

## Files

- `fruit-of-the-spirit.html` — the complete app as one self-contained HTML file, artwork embedded. Open it in any browser; no server or build step needed.
