# World Cities Map

A static, interactive world cities map built with Muse (Omi).

- 44 cities, sorted north to south by latitude by default
- Longitude shown as time zone in Time Zone mode; home-zone gold wash based on time zone (no geolocation)
- Static header bar; region colours: Asia-Pacific yellow, Europe blue, North America red, Africa brown, South America purple

## Files

- `world-cities.html` — the complete app as one self-contained HTML file. Open it in any browser; no server or build step needed.
