# Muse Apps

Small single-file web apps built with Muse (Omi), archived here as self-contained HTML snapshots. Each app lives in its own folder and runs by simply opening its HTML file in a browser — no server, no build step.

## Apps

- **[World Cities Map](world-cities/)** — interactive map of 44 world cities, sorted by latitude, with a time-zone mode and region colours. File: `world-cities/world-cities.html`

## Provenance

Each snapshot is exported from its Muse artifact. The copies here are the latest builds at export time, which may be newer than the versions served by the apps' public Muse links.
