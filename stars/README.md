# LA Star Map

A live interactive star map (planisphere) for Los Angeles, built with Muse (Omi). All times America/Los_Angeles.

- Rotating sky dome with constellations, planets, the Milky Way, and the Moon drawn as its actual phase (lit shape only)
- Jump buttons: Sunrise, Sunset, Moonrise, Now, Moonset, Fully Dark, Midnight, plus day-shift buttons
- Readout shows the Gregorian date, the Chinese lunar date, and the time; top bar shows the date and Moon phase
- Toggleable labels, constellation lines, and planets; optional explanation panel (off by default)

## Files

- `stars.html` — the complete app as one self-contained HTML file. Open it in any browser; no server or build step needed.
